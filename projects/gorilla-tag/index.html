Gorilla Tag

Software Engineer, ForwardXP·2020–2026

Unity · C# · PlayFab · Azure Functions · Redis · Cosmos DB · SQL · Photon PUN · Meta Quest

Links:Meta ↗·Steam ↗

Gorilla Tag is a VR movement game on Meta Quest that grew into one of the platform’s largest titles: 10M+ lifetime players, roughly 1M+ daily active users at its peak, $100M+ in lifetime revenue, and repeated #1 placements on the Meta Quest charts. It was also the first Quest application to pass 100,000 user reviews. I had the honor of building new gameplay systems and backend services for this game.

What I worked on

Ranked progression & multiplayer room validation: built the ranked progression system and the room validation that kept multiplayer sessions consistent and competitively fair, on Redis and PlayFab.

Cosmetics system: expanded the cosmetic equipment system from 4 slots to 10, and profiled the cosmetic asset pipeline to find and fix a handful of unusually expensive items, which produced roughly a 10% frame-rate improvement in the affected case.

Mobile prototype: adapted the game’s UI and interaction systems for an early non-VR mobile prototype, reworking input and layout for phone/tablet form factors instead of headset controllers.

Creator monetization: sole engineer on a creator-code monetization integration with a third-party partner (Nexus).

Code generation & redemption: designed and built the unique-code generation and redemption system used for both digital and physical (event-distributed) codes.

Player maps & voting: backend for player-created map storage and voting.
