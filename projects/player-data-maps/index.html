Player Data & Maps

Part of Gorilla Tag

Software Engineer, ForwardXP·2020–2026

C# · Cosmos DB · SQL

I worked on the backend for Gorilla Tag’s player-created maps, storing player-generated content and handling the voting system built around it, on Cosmos DB and SQL.

The interesting part of this system is unglamorous. It comes down to persistence and data-access patterns that hold up when a large number of players are reading and writing map/vote data concurrently, without the storage layer becoming the bottleneck for the rest of the live service.

Overview of the game this system runs inside: Gorilla Tag.
